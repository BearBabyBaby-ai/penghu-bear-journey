# 草案：測速照相機與科技執法（尚未實作）

狀態：2026-10-16 使用者同意（「可以 直接新增」），已於第16版實作。實作與草案的差異：資料改用**澎湖縣政府警察局**在澎湖縣政府開放資料平台公布的「澎湖縣固定測速照相設置地點表」與「澎湖縣科技執法地點」（比警政署全國資料更貼近澎湖、2026-08 仍有更新），警政署 7320 與新聞僅作參考；其餘依草案預設（圖層預設關、300／50 公尺、GPS 模式聲音＋震動）。

## 1. 要做什麼

在遊戲地圖上顯示澎湖的**測速照相**與**科技執法路口**，並在熊寶沿路前進（或開啟「我的位置」GPS 時）接近這些地點前提醒。只是提醒，不改變熊寶的移動規則（仍禁止瞬移、只走收錄道路）。

## 2. 資料來源

| 類型 | 來源 | 內容 | 備註 |
|---|---|---|---|
| 測速照相 | 警政署開放資料「測速執法設置點」（data.gov.tw 資料集 7320） | 設置縣市、鄉鎮、地址、管轄警局、經度、緯度、拍攝方向（direct）、速限（limit） | 只取「澎湖縣」 |
| 科技執法（路口） | 澎湖縣政府警察局公告 | 地點、偵測項目（闖紅燈、超速、未兩段式左轉、違規變換車道、未禮讓行人等）、啟用日期 | 目前沒找到全國統一的開放資料，要依公告人工整理 |

新聞（自由時報，2023-01）提到澎湖首批 3 處科技執法路口，於 2023-01-01 啟用。路口名稱與目前是否增設，都要以警察局公告為準（**未查證**）。

不使用「測速執法點取締件數資料」（13908），因為那是罰單件數統計，不是設置點。

## 4. 遊戲裡的呈現

- **圖層開關**：放在右側「地圖」選單，加一個「測速／科技執法」開關，**預設關閉**。
- **標記**：相機圖示加速限數字（例如 50）；科技執法用路口圖示。
- **不併入既有功能**：不進底部類別下拉，不算集章，不進探索圖鑑和問熊寶。
- **座標**：照原始資料，不吸附到道路。另外算出「最近道路上的提醒點」，只用來算距離。
- **熊寶行進提醒**：
  - 沿目前路線往前看 300 公尺，遇到提醒點就跳出「前方 300 公尺｜測速 50」。
  - 測速照相用拍攝方向判斷是否同向，反向不提醒。
  - 科技執法：進入路口 50 公尺內提醒。
  - 同一個點在同一段路程只提醒一次。
- **GPS 模式提醒**（搭配第 1 項「我的位置」）：
  - 用連續的 GPS 點算出實際行進方向與速度，時速低於 5 公里（步行或停車）不提醒。
  - 提醒時震動手機（`navigator.vibrate`）、播短提示音，畫面只當輔助。
  - 畫面上註明：「騎車時請勿操作手機；資料可能不完整，請以現場標誌與速限為準」。

## 5. 測試（新增 `tests/enforcement.mjs`，加入 `npm run check`）

- CSV 欄位解析，只留下澎湖縣的資料。
- 座標沒有被改動。
- 方向比對：同向會提醒、反向不提醒。
- 同一點不重複提醒。
- 讀不到工作表時會改用內建檔。
- 圖層關閉時不顯示、也不提醒。
